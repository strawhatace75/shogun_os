About

SHOGUN_OS — a client-side game hub. All data lives in localStorage.

Why some games open in a new tab: Sites like Poki, Coolmath, and NYT send X-Frame-Options: SAMEORIGIN and CSP frame-ancestors headers. Those are enforced by your browser before any JavaScript runs — there is no client-side bypass. The ↗ New Tab button opens the real game on the real site. It works perfectly there.

Want to embed them anyway? Deploy a server-side proxy (Cloudflare Worker, etc.) that strips those headers, then paste its URL into the Embed Proxy field above. CrazyGames, itch.io, and GameDistribution games are already embedded directly.
